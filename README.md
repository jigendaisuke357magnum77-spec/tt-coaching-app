# ノビシロノート(卓球コーチング記録アプリ)

企画書「卓球コーチング記録アプリ 企画書」の 4 画面を、スマホ 1 台で動く 1 ファイルの Web アプリとして実装した最小版です。

## 画面

| 企画書 | 実装 |
|---|---|
| 4-1 選手一覧 | トップ画面。ニックネームで登録(実名は使わない) |
| 4-2 試合記録 | 日付・相手のタイプ、スコアはゲームごとに「取った/落とした」と点数をタップ(勝敗は自動)、動画登録、再生中に「● しるし」でマーカー+ひとことコメント |
| 動画 | 端末の動画、または YouTube(限定公開)の URL を貼って再生。YouTube は公式の埋め込みプレイヤーで再生し、動画ファイルは保存しない |
| 全画面 | 「⛶ 全画面でしるし」で動画を画面いっぱいにしたまま、しるし・タグ・コメントを入れられる(横向きで最大) |
| しるし | 「得点」「失点」は1タップで記録(動画は止まらない)、「その他」は動画を止めてコメントを入力。振り返りで種類ごとに絞り込み。得点・失点の数と得点率を試合ごと・選手ごとに集計。セットの区切りがない長い動画でも、得点・失点のしるしから卓球のルール(11点先取・デュースは2点差・3/5/7ゲームマッチ)でゲームスコアと勝敗を自動計算 |
| ラリー自動検出(テスト版) | スマホ内の動画の音から打球音を拾い、音が途切れたところをラリーの終わりとして検出。感度・区切りの秒数を調整でき、検出結果を「正しい/違う/見逃し」で確かめて精度を測れる |
| ポイントごとの再生 | 「前の点/次の点」や一覧の ▶ で、前のしるし〜そのしるしの1ポイント分だけ再生して自動で止まる。全画面のまま一覧からしるしの種類・時刻を直したり、削除・取り消しができる |
| 練習動画 | その日の練習に動画を1本(端末か YouTube)。「いまの種目」を選んで「できた」「課題」を1タップ、「その他」はコメント。種目ごとの できた/課題 の数を表示し、「課題」はそのまま課題リストへ |
| 前回の伸びしろ・30秒記録 | 開いたらまず「前回の伸びしろ」を大きく表示。「⚡ 30秒で記録」で 練習/試合・今日の意識ポイント・やった技術(タップ)・次回の伸びしろ(必須)・メモ。前回の伸びしろが今日の意識ポイントに入る |
| 監督への共有 | 記録と試合の振り返りを、LINE などで送れる文章にして共有(サーバーは使わない) |
| 対戦相手の攻略メモ | 相手の名前(実名)・チーム名・戦型・用具メモ、効いた/効かなかったサーブ、得意/苦手コース、効いた戦術。名前・チーム・メモの中身・戦型で検索。試合記録から相手を選ぶと対戦成績が並ぶ。端末の中だけに保存 |
| 傾向(AI なし) | 直近の得点率の推移、失点の場面に多いタグ、練習動画の種目ごとのできた/課題、最近やった/やっていない技術、繰り返し出る伸びしろを集計し、「次の一手」の目安を1つ出す |
| 用具ログ | ラケット・フォア面・バック面ラバーを登録。貼った日からの練習・試合の回数と推定使用時間、自分で決めた替え時の目安に対する割合。貼り替えの履歴 |
| コース・回転の振り分け | 試合記録の「🎯 コース・回転を付ける」で得点・失点を1ポイントずつ再生し、どの球(サーブ/レシーブ/3球目/4球目/ラリー)・コース(フォア/ミドル/バック)・長さ(短い/長い)・回転(上/下/横/ナックル)を付ける。傾向タブで得点・失点の多いパターンと項目ごとの得点率 |
| タグ | しるしにサーブ・レシーブなどのタグ。振り返りでタグごとに絞り込み。タグはデータ管理で追加・削除 |
| 4-3 振り返り | しるし一覧(タップで動画がその場面へ)、次の練習で意識すること、身体操作メモ、指導者コメント |
| 4-4 練習メニュー記録 | 日付ごとの種目・時間・できばえ(★1〜5)・メモ。振り返りの課題をタップでメニューに追加 |

振り返り画面の「練習に追加」で課題が選手ごとの「課題」タブに溜まり、練習記録画面でタップすると
その日のメニューに入ります(試合 → 練習を一本につなぐ)。

## データの扱い

- すべて端末のブラウザ内(IndexedDB)に保存。サーバーも外部送信もありません。動画も端末内のみ。
- ブラウザのサイトデータを消すと記録も消えます。右上「⋯」→ データ管理 から JSON バックアップ(動画は含まない)を取れます。

## 起動方法

### パソコンで試す
`index.html` をブラウザで開くだけで動きます。

### スマホで使う
1. スマホで https://jigendaisuke357magnum77-spec.github.io/tt-coaching-app/ を開く
2. 共有メニューから「ホーム画面に追加」するとアプリのように起動できます

※ 公開されているのはアプリの画面(このファイル)だけで、選手の記録や動画は各自の端末から出ません。

### 同じ Wi-Fi のパソコンから配信する場合
```bash
python -m http.server 8000
```
スマホで `http://<パソコンのIPアドレス>:8000/` を開きます。
